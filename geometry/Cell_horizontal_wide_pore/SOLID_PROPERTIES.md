# 현재 고체 모델 및 입력값

고체는 고정된 2차원 원형 장애물이며 유체-구조 연성/고체 역학 방정식은 풀지 않습니다.
코드의 material=2는 고체 입자와 하단/모서리 벽의 구분 번호이지 실제 재료명이 아닙니다.
NMC의 측정 물성을 적용한 모델은 아닙니다.

| 구분 | 설정 |
|---|---|
| 운동/변형 | 위치 고정, 비변형, 고체 내부 유동 계산 없음 |
| 유동 경계 | BounceBackIncompressible: 정지 no-slip·불투과 벽 |
| 상장 경계 | PhaseFieldCurvedWall: 곡면 벽 wetting 처리 |
| 명목 접촉각 | 30° (코드에서 π/6 rad로 변환) |
| 접촉각 이력 | 전진/후퇴 접촉각 별도 모델 없음 |
| 입자 수 | 330개 |
| 직경 분포 | 난수 혼합 50–200 µm; 실제 50.1651–199.310 µm |
| 최소 입자 표면 간격 | 목표 20 µm; 실제 약 19.99992 µm (형상 허용오차 내) |
| 고체 면적 비율 | 공급원 제외, 약 0.601906 |
| 기공 면적 비율 | 공급원 제외, 약 0.398094 |
| 격자 간격 | 5 µm |
| 고체 밀도 | 물리 입력값 없음 |
| 탄성계수·포아송비·강도 | 물리 입력값 없음 |
| 열전도율·비열·열팽창계수 | 물리 입력값 없음; 열 방정식 없음 |
| 고체 표면에너지 | 고체-액체/고체-기체 개별 값 없음; 접촉각으로 wetting 조건 부여 |
| 화학 반응·흡수·팽윤·전기전도도 | 모델/물리 입력값 없음 |
| 별도 조도/마찰 계수 | 없음; 원형 경계와 격자 표현에 따른 효과만 존재 |
| 고체 자체 투과도 | 유체가 고체를 통과하지 않는 벽 가정; porous 영역의 유효 투과도는 별도 상수로 입력하지 않음 |

현재 `rho_liquid=1000`, `rho_gas=1.2 kg/m³` 및 동점성 `1e-6/1.5e-5 m²/s`는
액체/기체 값이며 고체 값이 아닙니다. 표면장력 `1e-5 N/m`도 액체–기체 계면 값입니다.
상장/유동 계산을 위한 wall 노드의 보조 필드 값은 물리적인 고체 밀도나 점성이 아닙니다.
명목 접촉각 30°는 검증용 입력값이며 NMC 실측값 또는 실제 격자에서 측정한 접촉각이 아닙니다.

근거: main.cpp의 Options, BounceBackIncompressible/PhaseFieldCurvedWall 설정,
THETA 필드, geometry.h 및 results/geometry_dx05의 형상/입자 검증 CSV.

접촉각은 현재 기본값 30°로 변경했습니다. 기존 결과 폴더의 60°는 과거 실행값이며 변경하지 않았습니다.
90° 대조군은 중립 젖음 조건으로, 곡면 경계 자체를 제거한 조건은 아닙니다.

기존 기체 밀도 100 kg/m³는 과거 수치 검증 조건입니다. 현재는 상온 공기 대표 상수로 변경했습니다.
