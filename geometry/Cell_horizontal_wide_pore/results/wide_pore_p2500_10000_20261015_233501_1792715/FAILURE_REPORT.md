# 확대 기공 형상 중단 분석

실행: wide_pore_p2500_10000_20261015_233501_1792715.

## 직접 중단 원인

7184스텝, 물리 시간 1.796 ms, 공급 압력 2500 Pa에서 FAIL.
최소 phi=-0.913785, 최대 phi=1.003484, 최소 격자 혼합 밀도=-0.722407,
최소 NS tau=0.478328, NS 통계 최대 격자 속도=27.047856.
이번 중단은 phi 상한 초과가 아니라 하한(-0.1) 이탈과 밀도/tau 검사 실패입니다.

## 진행 순서 및 위치

- 6562스텝에 NS 최대 격자 속도가 처음 0.1을 넘었습니다.
- 7160스텝에는 0.348965, 7183스텝에는 4.75614로 증가했습니다.
- 7183스텝 최소 phi=-0.059601에서 다음 스텝 -0.913785로 급락했습니다.
- 6500~7100스텝 최대 속도는 주로 (2.160~2.180, 0.795~0.805) mm 내부 pore(material 1)에 집중됐습니다.
- 이 부근 최대 속도 노드의 phi는 대략 0~0.02로 기체 측이며, 입자 #99 표면에서 약 4~18 µm 떨어져 있습니다. 인덱스는 제거되지 않은 입자의 0 기준 순번입니다.
- 최종 최소 phi 위치는 (2.145, 0.835) mm이며 입자 #220 표면에서 약 7.88 µm 떨어져 있습니다.
- 7100스텝 VTK 최대 격자 속도는 내부 0.188579, 외곽 0.009987입니다. 내부에서 먼저 커진 정황이며 외곽의 간접 영향까지 배제한 증명은 아닙니다.

마지막 VTK 최대 속도는 2087.12이고 NS 통계값 27.05와 다릅니다.
두 값은 같은 속도 평가 방식/시점이 아니므로 섞어 비교하지 않습니다.
마지막 VTK 최대 속도 노드의 phi=-0.110666은 rho=0이 되는 -1/9에 매우 가깝습니다.

## 원인 해석과 한계

현재 결합은 rho=0.1+0.9*phi, tau_NS=0.503+0.027*phi를 사용하며,
계면 힘을 rho로 나눕니다. phi가 -1/9 부근이면 rho는 0, NS tau는 0.5에 가까워져
수치 오차를 증폭할 수 있습니다. 이번 기록은 내부 기체 측 속도 증가 → phi 음의
이탈 증가 → 양의 밀도/완화시간 조건 붕괴 순서를 보여줍니다.
음의 밀도가 처음 속도 증가를 일으킨 원인이라고 단정하는 것은 아닙니다.

형상과 입자 검사는 PASS였고 공극률 0.398094, 최소 연속 입자 간격 약 20 µm,
공급원 연결 기공 비율 100%를 확인했습니다. 기하학적 검사 통과는 유체 계산의
안정성을 보장하지 않습니다. 입자 간격은 4격자로 개선됐지만 계면 두께도 4격자이며,
곡면의 계단형 격자 표현, wetting/계면력, 공급원과 충돌 처리의 민감도는 남습니다.

기존 형상은 9244스텝(2.311 ms)에 phi 상한 이탈로 중단됐으나 새 형상은
7184스텝(1.796 ms)에 하한/밀도/tau 이탈로 중단됐습니다.
형상 변경이 장시간 안정성을 개선했다고 판단할 수 없습니다.
공극률·입자 배치·유동량이 함께 바뀌었으므로 이것만으로 병목의 존재 또는 부재,
최초 원인 항을 확정할 수는 없습니다.

## 후속 검증 순서

1. 새 형상과 tau 0.53을 유지하고 압력 0 Pa에서도 10000스텝을 검증해 외부 압력 구동 필요 여부를 분리합니다. 0 Pa여도 강제 phi 공급원 및 계면력은 남습니다.
2. 같은 압력 0 Pa에서 sigma=0 대조군을 비교해 계면력 피드백을 분리합니다. 상장 sharpening/wetting은 그대로이므로 완전한 무물리 정지 대조군은 아닙니다.
3. 기체 NS tau=0.503의 민감도, 고체 표면 wetting, 공급원 강제 재설정을 각각 분리해 비교합니다. 기체 점성을 바꾸는 시험은 물성 변경 대조군으로 기록합니다.
4. 단순 clipping/상한 확대 대신 보존성을 포함한 phi 제한을 검토하되, 보정량과 질량 수지를 기록하고 속도 발산을 숨기지 않아야 합니다.
