# Cell_horizontal_wide_pore

현재 공기 물성 검증을 진행 중입니다: rho_gas=1.2 kg/m³, nu_gas=1.5e-5 m²/s,
접촉각 30°, 보정 RLB 및 보존형 phi 재분배를 적용한 30000스텝 시험입니다.
아래 과거 검증의 rho_gas=100 및 기존 BGK 조건과 구분해야 합니다.

현재 접촉각 기본값은 **30°**입니다. 기존 `validation_2000`, 최초 10000스텝 실행과
`zero_pressure_controls_v1`의 결과는 **60°에서 수행한 과거 결과**입니다.
30° 젖음/기체 대조군은 `wetting_gas_theta30_v1`에 별도로 저장합니다.
30°에서의 2500 Pa 장시간 안정성은 이번 0 Pa 대조군과 별도 검증 대상입니다.

기공 간격을 넓히기 위한 독립 형상입니다. porosity는 기공 면적 비율이므로
기공을 넓히는 목적에 맞춰 0.30에서 0.40으로 높였습니다.
공극률 증가만으로 최소 간격이 보장되지는 않으므로 입자 간 최소 표면 간격도
10 µm에서 20 µm로 높였습니다. 원본 폴더와 결과는 변경하지 않았습니다.

| 항목 | 이전 checking | wide_pore |
|---|---:|---:|
| 목표 공극률 | 0.30 | 0.40 |
| 실제 공극률 (공급원 제외) | 0.297851 | 0.398094 |
| 원형 입자 수 | 384 | 330 |
| 입자 직경 | 50–200 µm | 50–200 µm |
| 최소 입자 표면 간격 | 약 10 µm | 약 20 µm |
| 5 µm 격자에서 최소 간격 | 약 2격자 | 약 4격자 |

크기 4.3 × 1.835 mm, 861 × 368 노드, 공급원 1 × 0.5 mm를 유지합니다.
입자 크기 범위와 seed(20261014)는 같지만 입자 수와 좌표는 다시 생성했습니다.
입자 지름이나 기존 좌표를 단순 축소한 형상이 아닙니다.
모든 pore가 공급원과 연결되고 상단 내부까지 연결되는 형상 검사를 통과했습니다.
연속 원형 간격이 20 µm여도 실제 유효 수력 폭이나 투과도가 항상 두 배라는 뜻은 아닙니다.

유동 조건은 checking에서 통과한 2500 Pa / 0.25 ms 선형 ramp,
NS 및 상장 tau=0.53, NS BGK, legacy 공급원입니다.
하단 벽 / 상단·좌우 0 Pa 개방을 유지합니다.
밀도 1000/100 kg/m³, 동점성 1e-6/1e-7 m²/s, 표면장력 1e-5 N/m,
접촉각 30°, 계면 두께 4격자(20 µm)도 유지합니다.
phi clipping은 도입하지 않았고 기존 범위/양의 밀도/NS tau/유한성 중단 조건을 유지합니다.
최소 간격과 계면 두께가 모두 약 20 µm이므로 해상도·계면 두께 민감도가 없어지는 것은 아닙니다.

```bash
make -j2
./geometry_validate 5 results/geometry_dx05
python3 preview_geometry.py
./run.sh 2000
```

10000스텝 실행은 `./run.sh 10000`입니다. 스크립트는 매번 새 결과 폴더를 만들며,
진단은 매 스텝, VTK는 100스텝마다 저장합니다. 종료 후 VTK 검사를 자동 실행합니다.
현재 dt=0.25 µs이므로 2000스텝=0.5 ms, 10000스텝=2.5 ms입니다.
장시간 안정성과 물리 정확성은 별도로 검증해야 합니다.

## 초기 검증 결과

`results/validation_2000`: 2000스텝(0.5 ms), 공급 압력 2500 Pa에서 PASS.
매 스텝 진단 2001행, 저장 VTK 21개를 검사했습니다. 전체 구간 최대 격자 속도는 0.0988536입니다.
이는 단기 수치 검사이며, 이전 형상의 9244스텝 문제 해결 여부는 10000스텝 비교 후 판단해야 합니다.

현재 고체 모델의 입력값과 미설정 물성은 [SOLID_PROPERTIES.md](SOLID_PROPERTIES.md)에 정리했습니다.

## 접촉각 30° 및 젖음/기체 영향 분리

현재 기본 접촉각은 30°입니다. `run.sh`도 30°를 명시하며 결과 폴더명에 theta30을 포함합니다.
개별 실행에서는 `--contact-angle-deg 30`으로 지정합니다. 기존 60° 결과는 과거 조건 그대로 보존합니다.
0 Pa에서 기본 표면장력 1e-5 N/m를 유지하고 30°/90°와 기체 동점성
1e-7/1e-6 m²/s를 조합한 4개 대조군을 각 10000스텝까지 실행합니다.
NS 액체 tau와 상장 tau는 모두 0.53, 액체 동점성과 dt는 고정합니다.
기체 tau는 각각 0.503/0.53입니다. 기체 밀도는 두 경우 모두 100 kg/m³입니다.
기체 점성 변경은 물성과 충돌 완화를 동시에 바꾸는 민감도 시험이며 충돌 알고리즘만의 대조가 아닙니다.
90°는 중립 젖음 조건이지만 곡면 경계 처리는 유지합니다.

실행 스크립트: `python3 run_wetting_gas_checks.py` (기존 결과가 있으면 새 BASE 필요).
출력: `results/wetting_gas_theta30_v1/`. 매 스텝 진단, 100스텝 VTK를 저장합니다.

### 젖음/기체 대조군 완료

[검증 보고서](results/wetting_gas_theta30_v1/REPORT.md), [비교 CSV](results/wetting_gas_theta30_v1/comparison.csv).
0 Pa·기본 표면장력에서 기존 기체 점성은 30°/90° 모두 약 1750스텝에 실패했고,
기체 점성을 1e-6 m²/s로 높인 대조군은 두 접촉각 모두 10000스텝(2.5 ms)을 통과했습니다.
기체 점성 증가는 물성·수치 완화를 동시에 바꾸므로 원인 분리용이며 기본 기체 점성은 변경하지 않았습니다.
