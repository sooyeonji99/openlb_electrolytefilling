# phi 하한 이탈과 안정성 대조 결과 (2026-10-15)

단순한 고압/속도 제한 문제가 아니라, 초기 상장 수송의 undershoot와
계면 힘–유동–혼합 물성의 결합 불안정이 확인됐습니다. 단일 코드 오류를
특정한 결과는 아니며, 아래는 원인 분리 실험과 현재 검증 한계입니다.
모든 실험은 같은 축소 형상과 동일한 물리 입자 목록을 사용합니다.
기본 물성과 초기화/압력 ramp는 해당 항목에서 명시한 경우만 바꿨습니다.
수치 PASS는 기록한 시간까지 유한성/phi/양의 밀도/NS tau 검사를 통과했다는
뜻이며, 속도 제한이 비활성화된 상태이므로 정확성 PASS와 다릅니다.

5 µm의 기본 3000스텝 목표는 0.75 ms, 5000스텝은 1.25 ms입니다.
0 Pa라도 reservoir의 액상 고정·젖음·계면 힘은 유지됩니다. finite 대조는
초기 상태만 같게 두고 이후 강제 갱신을 중단한 다른 공급 조건이며,
sigma0 대조는 NS 표면장력 힘을 제거하지만 상장 sharpening/벽 처리는 유지합니다.
TRT는 MAGIC=3/16의 이번 설정이며, 모든 TRT 모델이 실패한다는 뜻은 아닙니다.
ITRT는 설치된 gasStorage2d 예제의 TAU_MINUS=1.5 및
MAXNABLARHO=(rho_l-rho_g)/W 설정을 사용했습니다. limiter는 넣지 않았습니다.

## phi가 음수로 내려가는 경로

현재 상장은 conservative Allen–Cahn BGK입니다. 액체 NS tau를 상장 tau에도
기본 사용했기 때문에 상장 tau=0.53, omega=1.88679였습니다. BGK 갱신의
기존 분포 계수 (1-omega)는 -0.88679이며, 계면 sharpening·대류·벽 처리·
공급원 갱신과 합쳐졌을 때 phi의 [0,1] 최대원리를 강제하는 구성은 아닙니다.
계면 부근 음의 phi는 물리적인 음의 액체량이 아니라 수치 undershoot입니다.

초기 7스텝 부근에는 0 Pa와 sigma0에서도 약 -0.01866의 undershoot가
관측됐습니다. 그때 속도는 작았습니다. 즉 초기 undershoot를 고압이나
빠른 유동만으로 설명할 수 없습니다. 상장 tau=1 대조에서는 초기 12행의
음의 undershoot가 사라졌습니다. 유한 reservoir 대조에서는 갱신 중단 후
2스텝에 공급원 안쪽 모서리 (1.655,0.495) mm에서 phi=1.12458이 됐으나,
상장 tau=1에서는 50스텝까지 최대 overshoot가 약 2.1e-6 수준이었습니다.
초기 tanh 계면과 reservoir phi=1 재설정이 완전한 평형 상태는 아닙니다.
이것은 초기화/상장 이산화의 결합 민감도 근거이며 특정 한 줄의 버그 증명은 아닙니다.

이후 기존 sigma>0 조건에서는 속도가 커지면서 phi 진동이 성장했습니다.
기존 가압에서 속도 0.1 초과는 2028, 0.3 초과는 2474, 큰 하한 이탈은
2542스텝입니다. 0 Pa에서도 실패했지만 0 Pa+sigma0은 속도가 사실상 0인
상태로 3000스텝을 통과했습니다. 이 대조는 후기 불안정에서 계면 힘과
NS 유동의 피드백이 중요하다는 근거입니다.

설치된 LiangPostProcessor는 clip 없이 다음을 계산합니다.

- rho_lattice = 0.1 + 0.9 * phi
- tau_eff = 0.503 + 0.027 * phi (SCALAR=1인 유체)
- NS force = external_force + capillary_force / rho

phi=-0.111111 부근에서 rho=0이고 tau=0.5입니다. phi=-0.1에서도 이미
rho=0.01, tau=0.5003으로 초기 기체보다 훨씬 민감합니다. 5 µm 기본 가압
종료 시 min_rho=-0.02074, min_tau=0.499378을 실제 field에서 확인했습니다.
2 µm 무가압도 1180스텝에 min_rho=-0.02234, min_tau=0.499330이었습니다.
이 단계에서는 혼합 물성이 비물리적이며 기존 힘의 rho 나눗셈이 불안정을
증폭할 수 있습니다. 최초 오차와 후기 증폭 원인을 구분해야 합니다.
phi를 단순 clip하거나 하한을 더 낮추는 방식으로 해결하지 않았습니다.

## 충돌 모델 및 공급원 대조 해석

일반 TRT는 기존보다 먼저 실패했습니다. 계면 ITRT는 실패 시점을 늦췄지만
10 kPa에 도달하기 전에 실패했습니다. 이번에 시험한 충돌 변경만으로는
기존 상장 tau=0.53 조건을 안정화하지 못했습니다.

공급원 CH 분포/이력 재설정과 공급원 capillary 결합 분리도 실패했습니다.
따라서 단순한 공급원 history reset이나 공급원 내부 힘 제거가 충분한
수정은 아닙니다. 공급원의 초기 계면·stencil·물리적인 inlet 모델 자체가
완전히 검증됐다는 뜻도 아닙니다.

가장 유망했던 대조는 상장 tau를 NS tau와 분리해 1.0으로 둔 조건입니다.
5 µm에서는 10 kPa 도달 후 0.25 ms까지 계산했고 최대 격자 속도는 약 0.090,
phi 범위는 약 [0,1.030]였습니다. 초기/중간/종료 VTK 필드와 실제 공급원
압력을 별도로 검사했습니다.
2 µm는 1300스텝(0.052 ms)까지 phi/밀도 검사를 통과했지만, 격자 속도는
0.3을 넘었습니다. 그러므로 2 µm 장시간 안정화 또는 저마하수 정확성을
검증한 후보라고 해석하면 안 됩니다.

## 상장 tau=1은 물리적으로 동등한 변경인가?

아닙니다. 유체 밀도/점도/dt는 유지하지만 phase mobility는 변합니다.
M = (tau_phase-0.5) * dx^2 / (3 dt)이며 0.53→1.0은 M을 16.6667배로 합니다.
현재 두 격자에서 M은 1e-6→1.66667e-5 m²/s입니다. 따라서 통과한 충전율을
그대로 기존 모델과 물리적으로 비교하거나 실제 침투 예측으로 확정하면 안 됩니다.
phase mobility/계면 폭에 대한 수렴, 모세관/Laplace/Washburn 재검증 및
정확한 source/출구 수지가 필요합니다. 5초 안정성 검증은 수행하지 않았습니다.
근거 모델 및 mobility 관계: https://arxiv.org/html/1710.09541 (식 1, 14).

## 코드와 재현

기존 생산 기본값(BGK, legacy source, phase tau=liquid NS tau)은 재현을 위해
유지했습니다. main.cpp에 --ns-collision, --source-mode, --phase-tau, --sigma
검증 옵션과 min_rho_lattice/min_tau_eff 진단을 추가했습니다. 모든 검사/결과는
각 폴더의 run_config.csv와 comparison.csv/json에 기록했습니다.
NS rho<=0 또는 tau_eff<=0.5도 오류로 중단합니다. 속도 크기 중단은 사용자
요청대로 비활성화 상태이며 bulk phi clipping은 없습니다.

검증한 5 µm 후보 재현(새 경로 사용):

```bash
./main --dx-um 5 --phase-tau 1 --ns-collision bgk --source-mode legacy \
  --reservoir-pressure-pa 10000 --pressure-ramp-s 0.001 \
  --steps 5000 --diagnostic-every 1 --output-every 1000 \
  --output results/stability_followup_tau1
```

이 명령은 mobility를 바꾸는 안정성 대조입니다. 물리적으로 검증된 최종
프로필이나 2 µm의 장시간 실행 권장값으로 제시하는 것은 아닙니다.
실험별 상세 옵션 및 재실행 방법은 validation/README.md를 참조하세요.
