# 가속도 제어(g 단위) 검증

기본1g=9.81m/s²의 고정 가속도 진폭. 위상은10→100→10Hz의 적분값을 사용하며 공급압력2500Pa를 유지한다.

|시험|결과|범위|
|---|---|---|
|smoke_g_initial_rest|PASS|200step·MPI4프로세스·VTK/유한성 검사|
|smoke_g_active_up|PASS|200step·MPI4프로세스·VTK/유한성 검사|
|smoke_g_all_transitions|PASS|640step·MPI4프로세스·VTK/유한성 검사|

기본 조건 초기200step, 실제1g 진폭으로 pre-rest만0으로 둔 상승 시작200step, 시간을 압축한 전체 구간 전환640step을 검증했다. 전환 시험도 진폭1g를 유지했다.

전체1.06초의 처방 파형을10µs 간격으로 확인해 가속도가±9.81 이내임을 확인했다. 2g는2배,0g는0이며 위상 연속성과55주기도 검사했다. 전체1.06초 유동 계산은 시작하지 않았다.

변위·속도 경로는 지정하지 않는다. 중력은 별도로 더하며 기본 설정의 총 가속도는−19.62~0m/s²이다. 이전 변위 제어 결과는displacement_control_previous에 보존했다.
